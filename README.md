# 多元性別・課堂反思作業

「生命教育與社會服務」課程使用的單頁互動作業。學生可在瀏覽器填寫、下載文字檔，或列印成 PDF。

## 使用方式

直接開啟 `dist/index.html`，或將 `dist/` 設為靜態網站根目錄。

## 隱私

學生填寫內容只儲存在其目前使用的瀏覽器，不會傳送或儲存到伺服器。

## 資料來源

概念改編自 Trans Care BC, *Exploring Gender Diversity*（使用者提供之〈多元性別.pdf〉，頁 1-2）。原始資料標示 Trans Care BC Provincial Health Services Authority，角色插圖 Drawing Change。作業文字為課堂教學改寫。

首頁插圖以 OpenAI Image Generation 製作，呈現尊重、多元的共同學習情境。
